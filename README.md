# ⚡ Abhiram Darbha — Personal Portfolio

A modern, interactive, dark-themed personal portfolio website built with **React**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**. Features custom micro-interactions, a music player with spring physics animations, and a serverless contact form integration.

🚀 **Live Demo:** [abhid234.github.io/portfolio-website](https://abhid234.github.io/portfolio-website/)

---

## ✨ Features

* **🎨 Modern Dark UI:** Styled with a custom `#0A0A0F` aesthetic, cyan accents, grid backgrounds, and glassmorphic cards.
* **🎵 Animated Music Player:** Floating mini player that expands into a full audio card powered by `Framer Motion` spring animations, complete with vinyl spin effects and track seeking. This plays some of my favourite songs.
* **📜 Interactive Pages:**
  * **Home:** Sweeping title animations, a cool animation around my picture, education cards, current focus areas, and animated statistics.
  * **About:** Rotating personality traits, hobby showcases, daily routine timeline, and future goals list.
  * **Projects:** Pinned project cards highlighting GitHub repositories and live builds.
  * **Contact:** Asymmetric layout featuring direct email links, location info, social badges, and a functional contact form powered by **Web3Forms**.
* **⚡ Blazing Fast:** Powered by Vite 8 and React 19 for instant page loads and smooth client-side routing.

---

## 🛠️ Tech Stack

* **Framework:** [React 19](https://react.dev/) + [Vite 8](https://vitejs.dev/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Animations:** [Framer Motion](https://www.framer.com/motion/)
* **Icons:** [Lucide React](https://lucide.dev/) + [React Icons](https://react-icons.github.io/react-icons/)
* **Routing:** [React Router](https://reactrouter.com/) (`HashRouter` for GitHub Pages compatibility)
* **Contact Integration:** [Web3Forms API](https://web3forms.com/)
* **Deployment:** [GitHub Pages](https://pages.github.com/) (`gh-pages`)

## 🚀 Getting Started Locally

Follow these steps to clone and run the project locally on your machine:

### 1. Clone the repository
```bash
git clone [https://github.com/Abhid234/portfolio-website.git](https://github.com/Abhid234/portfolio-website.git)
cd portfolio-website
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```

Open `http://localhost:5173` in your browser to view the application.

---

## 📦 Deployment

This repository is configured for automatic deployment to GitHub Pages using the `gh-pages` package.

To build and deploy the latest changes:
```bash
npm run deploy
```

This command automatically builds the project into the `dist/` directory and pushes the compiled assets to the `gh-pages` branch.
